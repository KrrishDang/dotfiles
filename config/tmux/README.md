# tmux

My cross-platform tmux configuration.

## Requirements

- tmux >= 3.3
- Tmux Plugin Manager (TPM)

## Plugins

- tmux-plugins/tpm
- tmux-plugins/tmux-sensible
- catppuccin/tmux

## Installation

Clone TPM:

```bash
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

Reload tmux:

```bash
tmux source-file ~/.tmux.conf
```

Install plugins:

```
Prefix + I
```
